# 🛠️ UrbanFix On-Demand Services Mobile App

> Production-ready React Native & TypeScript on-demand home services marketplace and expert booking platform with upfront dynamic pricing, surge management, slot availability dispatch, and verified artisan profiles.

---

## 🌟 Key Capabilities
- **Dynamic Service Pricing Engine**: Integer-paise precision cost breakdown covering base inspection labor, surge multipliers, consumable parts, and 18% statutory tax calculation.
- **Service Warranty & Guarantee**: Automatic 30-day post-service warranty tracking and claim window handling.
- **Verified Technician Dispatch**: Real-time artisan assignment badge, star rating aggregates, and dynamic ETA estimation.
- **Zero-Float Accounting**: All billing computations are executed strictly in sub-paise integer arithmetic to eliminate floating-point rounding discrepancies.

---

## 🛠️ Architecture & Tech Stack
- **Framework**: React Native / Expo
- **Language**: TypeScript (Strict Mode)
- **Styling**: Artisan Indigo Design System (`src/theme`)
- **Booking Engine**: `src/utils/serviceBookingEngine.ts`
- **UI Components**: `src/components/ServiceBookingCard.tsx`
